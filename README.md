# Anvi

If you want to produce more and consume less, Anvi is for you.

You can just lock your screen and you won't get out until you have written enough words.

Anvi is a Linux application for Wayland.

Disclaimer: still a work-in-progress.


## Development
If you have nix installed, just run `nix develop` and your environment is ready.

Otherwise you have to install the dependencies manually.
